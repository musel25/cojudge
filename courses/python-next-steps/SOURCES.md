# Python Next Steps sources

The course follows the 25 Python First Steps exercises. The ideas below came from public practice sites and repositories. The Cojudge task text, Spanish summaries, examples, tests, Java markers, and Python answers were written for this course. No source instructions or solutions were copied.

| Cojudge tasks | Source idea |
| --- | --- |
| 5, 14, 15, 17, 30, 37 | [Practice Python exercises](https://www.practicepython.org/exercises/) |
| 18, 21, 23 | [CodingBat Python list and string exercises](https://codingbat.com/python) |
| 19, 24, 26, 28, 31 | [Exercism Python practice track](https://exercism.org/tracks/python/exercises) and its [MIT-licensed repository](https://github.com/exercism/python) |
| Function and collection sequence | [Python Koans repository](https://github.com/gregmalcolm/python_koans), MIT licensed |

The source link in a problem's answer page identifies the closest source idea. Adaptations reduce English reading and make input, result, and boundary rules explicit. Numeric list answers are checked as values, so spaces and line breaks do not decide the verdict.
