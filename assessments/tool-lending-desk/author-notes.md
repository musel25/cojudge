# Tool Lending Desk author notes

Berkeley Public Library has a separate tool catalog. Staff can place holds, and borrowers get a notice when a tool is ready. Brooklyn Public Library releases an unclaimed tool when its pickup window ends. These examples informed the revised catalog, stocktake, and pickup language. [Berkeley tool lending FAQ](https://www.berkeleypubliclibrary.org/locations/tool-lending-library/tools-faq) · [Brooklyn tool lending policy](https://www.bklynlibrary.org/tool-library)

The original exercise counts copies by model. Its timed records are reminders for desk staff. Checkout and allocation happen elsewhere in the fictional workflow. A reminder may overlap another reminder for the same model. The revision log is an exercise rule for checking earlier counts.

The prose review keeps the original Python methods, cases, answers, and judging rules.
