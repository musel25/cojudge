## Learn

A set keeps each value once. Use set(nums) to remove repeated values before you count them.

```python
nums = [2, 2, 5]
print(len(set(nums)))  # 2
```

This code prints:

```text
2
```

## Your task

**Example 1**

Input:

```text

```

```text

```

Why: The different values are 2 and 5, so the count is 2.

**Example 2**

Input:

