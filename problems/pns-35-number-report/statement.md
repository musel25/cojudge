## Learn

A function can return several useful values. Use len(), sum(), max(), and set() on the same list.

**Idea en español:** Puedes combinar len(), sum(), max() y set() en un reporte.

```python
nums = [2, 2, 5]
print(len(nums), sum(nums))  # 3 9
```
