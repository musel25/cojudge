## Learn

The first letter of each word can make a short name. upper() makes those letters capitals.

```python
word = "cat"
print(word[0].upper())  # C
```

This code prints:

```text
C
```

## Your task

Read one line of words separated by spaces. Take the first letter of each word. Print those letters together in upper case, with no spaces. Words contain only English letters. A blank line gives an empty line.

**Example 1**

Input:

```text
portable network graphics
```

Result:

```text
PNG
```

Why: The first letters of portable, network, and graphics are P, N, and G.

**Example 2**

Input:

```text
Blue sky
```

Result:

```text
BS
```

Why: The first letters of Blue and sky are B and s. Change s to S.
