## Learn

The first letter of each word can make a short name. upper() makes those letters capitals.

```python
word = "cat"
print(word[0].upper())  # C
```

This code prints:

```text
C
```

## Your task

Read one line of words. Take the first letter of each word. Show the letters together in upper case. Words contain only English letters. Spaces separate words.

**Example 1**

Input:

```text
portable network graphics
```

Result:

```text
PNG
```

Why: The first letters of portable, network, and graphics are P, N, and G.

**Example 2**

Input:

```text
Blue sky
```

Result:

```text
BS
```

Why: The first letters of Blue and sky are B and s. Change s to S.
