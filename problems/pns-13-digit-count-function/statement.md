## Learn

A while loop can remove one digit at a time. The // sign divides and keeps only the whole-number part.

**Idea en español:** La división // quita la parte decimal. Puedes usarla para quitar el último dígito.

```python
number = 123
number = number // 10
print(number)  # 12
```
