## Learn

A divisor divides a number with no remainder. For example, 2 is a divisor of 6 because 6 % 2 is 0.

**Idea en español:** Un divisor deja residuo 0 al dividir. El operador % da el residuo.

```python
print(6 % 2)  # 0
```
