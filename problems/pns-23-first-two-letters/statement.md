## Learn

A string is a sequence of characters. A slice such as text[:2] takes at most the first two characters.

**Idea en español:** Un corte como [:2] toma hasta dos caracteres.

```python
text = "python"
print(text[:2])  # py
```

## Your task

**En español:** Lee una línea de texto. Muestra sus primeros dos caracteres, o los que existan.

**Example 1**

Input:

```text
python
```

Result:

