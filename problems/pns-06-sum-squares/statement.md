## Learn

You can use a loop result in a calculation. number * number is the square of number.

```python
number = 3
print(number * number)  # 9
```

This code prints:

```text
9
```

## Your task

Read n. Add 1 * 1 + 2 * 2 + ... + n * n. Show the total. If n is 0, show 0. The test values use 0 through 100.

**Example 1**

Input:

```text
3
```

Result:

```text
14
```

Why: The squares are 1, 4, and 9. Their sum is 1 + 4 + 9 = 14.

**Example 2**

Input:

```text
0
```

Result:

```text
0
```

Why: There are no numbers from 1 through 0, so the sum is 0.
