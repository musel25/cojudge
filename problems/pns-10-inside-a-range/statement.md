## Learn

A function can receive more than one value. These values are its parameters. A result of 1 can mean yes, and 0 can mean no.

**Idea en español:** Una función puede recibir varios valores. Aquí, 1 significa sí y 0 significa no.

```python
def is_zero(value):
    return value == 0
```

**En español:** Devuelve 1 si value está entre low y high, incluidos los extremos. En otro caso, devuelve 0.
