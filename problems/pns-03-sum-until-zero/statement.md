## Learn

A while loop repeats while its condition is true. A special input value can tell the loop to stop. Here, 0 is the stop value.

**Idea en español:** Un ciclo while continúa mientras su condición sea verdadera. El 0 detiene este ciclo.

```python
value = int(input())
while value != 0:
    value = int(input())
```
