## Learn

A dictionary links a key to a value. Here, the key is a word and the value is its count.

**Idea en español:** Un diccionario guarda un valor para cada clave. Aquí la clave es una palabra.

```python
counts = {}
counts["cat"] = 2
print(counts["cat"])  # 2
```

## Your task

**En español:** Cuenta cuántas veces aparece la palabra buscada en la primera línea.

**Example 1**

Input:

```text

cat
```

Result:

```text
2
```

**Example 2**
