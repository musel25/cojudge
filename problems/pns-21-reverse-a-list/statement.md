## Learn

A slice with step -1 reads a list backward. It makes a new list.

**Idea en español:** El corte [::-1] crea una copia en orden inverso.

```python
nums = [4, 8, 3]
backward = nums[::-1]
print(backward)  # [3, 8, 4]
```
