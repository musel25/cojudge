## Learn

A while loop can grow a value until it reaches a goal. Keep changing the value inside the loop so it can stop.

**Idea en español:** Cambia el valor dentro del ciclo while para que pueda terminar.

```python
power = 1
while power < 8:
    power = power * 2
```
